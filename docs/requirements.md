# 已确认需求

本文件保存当前约束与稳定编号，细节由对应规范维护；不记录逐轮执行、个人环境状态或一次性操作授权。最新明确决定优先，未确认建议不作为要求。修改规则时原位更新，维护方式见[文档索引](README.md#文档维护)。

| DATA-03 | 每个开放章节独立推进，固定顺序为必读资料、两类并行练习、测验。没有必做项目的阶段直接通过。 | [内容规范](content-authoring.md)、[产品说明](product.md) |

| DATA-08 | 题目来源类型只保留“AI生成/导入”，后台手动录入归入导入；参考资料及页码为可选依据。草稿与可用/停用状态分开，未来AI出题进入审核流程；不可伪造真实AI生成能力。 | [内容配置](content-authoring.md)、[后台设计](design/teacher-interface.md) |
| DATA-09 | 教学内容通过显式导入或后台维护，与程序更新解耦；启动不自动导入固定课程和旧题。保留数据库、私有文件及学习记录，普通迁移不承担业务清空。 | [架构](architecture.md)、[开发手册](development.md) |

## 教学、测验与脚本

| 编号 | 当前约束 | 规范归属 |

| LEARN-01 | 教师从章节详情维护资料和活动。客观题、编程题分别发布练习，测验可以有多份。选做练习不阻塞测验。 | [内容规范](content-authoring.md)、[产品说明](product.md) |
| LEARN-02 | 勾选必读后默认读完整份。高级设置可按页范围、任意不同页数和有效时长组合。视频按有效观看时长和片段计算。 | [内容规范](content-authoring.md)、[产品说明](product.md) |
| LEARN-03 | 阅读位置独立于参与页数和累计时长。后台标签页暂停计时，重复阅读同一页只计一页。 | [内容规范](content-authoring.md)、[产品说明](product.md) |
| LEARN-04 | 练习只用单题模式，提供上一题、下一题和侧栏目录跳转；每题“提交答案”，错误可改正后重新提交，跳题保留各题草稿和反馈。 | [游戏设计](design/game-interface.md)、[内容配置](content-authoring.md) |
| LEARN-05 | 单元测验支持单题与整卷两种排版，共用答案；全部作答后从题目目录上方统一交卷。交卷后服务器锁卷，展示逐题对错，不能修改或绕过整卷接口逐题提交。 | [HTTP 契约](api-contract.md)、[游戏设计](design/game-interface.md) |
| LEARN-06 | 测验满分 100，按 `correct_count * 100 // total` 向下取整；未判完为 `null`，不能显示成 0 分。所有题目真实判定结束即完成测验，全对另行表示；错误答案不阻断一次性测验剧情，基础设施故障不算答错。 | [产品](product.md)、[HTTP 契约](api-contract.md) |
| LEARN-07 | 四位固定角色在各自室内接待学生，根据本章任务的可用、锁定、进行中和完成状态选择对白。 | [内容规范](content-authoring.md)、[产品说明](product.md) |
| LEARN-08 | 角色提示从真实进度生成。无活动时说明尚未布置，有前置未满足时告知章节与要完成的任务。 | [内容规范](content-authoring.md)、[产品说明](product.md) |
| LEARN-09 | 测验Python提交通过独立go-judge容器执行；练习提交在浏览器重新评测全部公开样例，后端校验回传结果、幂等保存完成记录，不进入judge队列。go-judge与db/api/web统一部署，任务使用现有数据库持久队列。API主机不执行学生代码，隐藏用例不外泄；未知派发先对账，旧成绩不重评。 | [架构](architecture.md)、[部署](development.md#可选服务与配置) |
| LEARN-10 | 教师从课程的一个章节选择多个知识点，对每个目标设置答对总数、各题型最低数量或两者组合。按学生抽取满足全部目标的首批题；多知识点题只分配给一个目标，发布校验与抽取均全局去重。 | [内容配置](content-authoring.md#练习与一次交卷测验) |
| LEARN-11 | 首次正式答错一题时，从同一目标剩余题池追加一道新题。学生可立即修改并重新提交，同一题重复答错不再追加。 | [内容配置](content-authoring.md#练习与一次交卷测验) |
| LEARN-12 | 个人题单在重进时恢复；每次补题增加题单总数。所有知识点达标且个人题单全部通过才完成，包括追加题与错题订正。任务与剧情使用同一服务端证据。 | [游戏设计](design/game-interface.md#练习与单元测验) |
| LEARN-13 | 教师编辑交互练习题的 HTML、CSS、JS，在预览中试答并查看助教状态。编辑器保存时试跑脚本，可用题须通过校验。仅练习可选用，学生在卡片内操作、提交或重置本题草稿。服务端核对实际提交值后记录判定。 | [编写指南](interactive-practice-authoring.md)、[HTTP 契约](api-contract.md) |
