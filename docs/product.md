# 产品能力与学习流程

Pythontopia Reborn是面向Python初学者的Web学习RPG。学生在小镇内学习，教师通过独立后台维护班级与课程；业务约束和编号见[需求](requirements.md)。

## 学生学习

学生使用学号登录并加入班级，课程资料、进度、作答和成绩按班级隔离。小镇中的角色通过对白引导阅读、练习和测验，日常移动、翻页及剧情不触发模型调用。

内置主线为arrival“初来小镇：第一堂 Python 课”：镇长欢迎，馆员引导阅读，教练组织练习，镇长主持测验并按真实结果反馈。其他章节可以保留资料与知识点，由教师安排开放，不自动生成额外主线。

阅读支持文本、PDF/演示文稿及视频。可用的已审校讲稿和配音提供试听；播放器不替代阅读完成证据。学习工作区保留阅读位置、草稿和助教会话，界面规则见[游戏规范](design/game-interface.md)。

知识点练习根据教师设定的目标抽取个人题单，首次答错可追加一道题。学生需达到目标并答对全部已分配题目，包括订正错题。测验可切换单题或整卷排版，统一交卷后锁定答案。Python题可在浏览器试运行公开样例；练习点击“提交代码”后重新在浏览器评测全部公开样例，通过后保存完成记录，显示“正式提交”和通过用例数量。测验统一交卷后由隔离判题服务评测公开与隐藏用例。后台评测管理仅管理服务器评测。基础设施失败不算学生答错。

学生主动提问才调用授权角色助教。阅读以当前授权材料为依据，练习提供提示；内置章节测验禁用助教。未配置模型或材料不可用时，界面如实说明。

## 教师管理

教师维护班级、学生、章节、知识点、资料、题库、活动、角色与流程；管理员可在同一后台维护任何班级、转交班级、管理教师和学生账号，以及查看全局任务并管理全站服务。正式删除班级解除学生绑定，保留学生账号、提交与成绩。教师可进入自己班级的专属体验存档，体验记录不进入正式学生统计。

课程通过格式3的完整目录包显式导入，形成班级独立实例。后台编辑当前内容，导出用于备份和交换；服务重启不自动导入。共享导出包与默认包的管理规则见[内容规范](content-authoring.md#班级独立编辑与导入导出)。

教学流程支持多轮对白、多个结束节点和基于真实学习状态的条件分支；教师可以配置系统地图上的角色和交互，不能改写固定地形、碰撞或传送结构。编写方法见[教学流程编写](content-authoring.md#教学流程编写)。

教师打开「快速编排」，选择章节、课件和知识点，用「学课件、做练习、做测验」搭建课程。教师可以加入小镇日常闲聊和图书馆书架支线，指定学生从哪章初到小镇，在哪章听镇长作全课总结。正在续编的课程可暂不指定最终章。练习和测验可以沿用统一的每章总题数，也可以为某章、某个知识点指定题量和题型。教师核对预览后即可生成流程，进入小镇体验。[按模板快速编排](content-authoring.md#按模板快速编排)

资料与题目独立管理并可归属多个章节。讲稿由教师显式生成、审校后发布，可合成配音并随包交换。内容更新或删除先检查影响，保留学习证据，不以课程整理为由清空学生记录。

## 支持范围与限制

- 当前交付以1920×1080桌面Chromium和键盘鼠标为基准；保留响应式能力，但不承诺手机、触屏、超宽屏或手柄已验证。
- 固定世界随程序发布，真实课程、媒体和环境配置由部署者私有维护，不随公开仓库提供。
- 有学习记录的班级暂不支持直接替换成另一门课程；同课程更新必须通过影响预览和保留证据校验。
- 模型、语音、转换、外部存储与正式判题需要各自配置及目标环境验证；缺少某项服务不应伪装为成功。配置与排查见[开发手册](development.md#可选服务与配置)。
- 曾记录特定GPU上的间歇黑线和触屏对白问题（2026-11-04/05），原场景尚未确认根因；本次文档整理未复验，不能据其他设备截图认定已解决。
