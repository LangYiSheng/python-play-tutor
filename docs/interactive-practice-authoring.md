# 如何制作交互练习题

交互练习题适合让学生操作一组控件、观察结果，再提交自己的作答。例如，学生可以改变 `range` 的步长，观察哪几盏灯亮起，再询问助教为什么最末一盏灯没有亮。教师在题库编写，学生直接在练习题卡上操作。该题型仅用于练习。

## 从一道模板开始

1. 在教师后台打开「题库」，新增题目，题型选择「交互练习题」。打开「编写与试答」，展开「从示例开始」，选择教学示例并点击「试用示例」。点击「用此示例编写」并确认后，示例的题名、题干、源码和正确提交值会复制到当前草稿。也可直接从空白题面开始编写。
2. 在「题目信息」中编写公开题干。写明初始条件、可以怎样操作，以及什么结果算完成。背包题要写清「从栈底到栈顶」，路灯题要写清哪些编号应当亮起。助教会收到题干，所以目标和规则要写在这个字段，即使画面里也展示了相同的信息。
3. 在「编写与试答」中编辑 HTML、CSS、JavaScript，在「私有判定」中填写正确提交值（JSON）。运行预览，先做错一次，再完成一次。每次分别点击「检查预览作答」和「查看助教收到的状态」，核对反馈、提交值和学生当时看到的画面。
4. 保存并设为可用。将题目加入练习活动。需要学生能提问时，在活动中启用助教并选好角色。可先保存为草稿，随后继续修改。

| 内置模板 | 学生操作 | 助教能读到的现场信息 |
| --- | --- | --- |
| 点亮小镇路灯 | 调整起点、终点和步长 | 三个参数和实际亮灯编号 |
| 整理采集背包 | 从栈顶取出，或从物架放回 | 从栈底到栈顶的物品名称、物架上剩余物品 |

## 先决定哪几种数据值得保留

以路灯题为例，下列四种数据服务于不同的操作。教师可以为它们选用不同的 JSON 结构。

| 数据 | 例子 | 谁使用 |
| --- | --- | --- |
| 草稿 | `{"start":0,"stop":8,"step":2}` | 学生切题再回来时，用它还原三个控件 |
| 当前公开状态 | `{"起点":0,"终点":8,"步长":2,"当前亮灯编号":[0,2,4,6]}` | 学生点发送时，助教结合题干解释当前现象；教师也能在预览中查看 |
| 本次提交值 | `[0,2,4,6]` | 脚本把学生实际得到的结果和正误反馈一起交给平台 |
| 私有正确提交值 | `[1,3,5,7]` | 服务端核对本次提交值。题卡与助教均不会收到这个字段 |

公开状态应让没看到画面的人也能理解。用有意义的字段名，注明方向、单位和当前步骤。背包题里，学生刚取出栈顶的水晶时，回调返回 `{"背包从栈底到栈顶":["药草"],"物架上":["蘑菇","水晶"]}`。助教据此就能解释下一次取出的是哪件物品。只返回这次提问需要的公开信息，私有答案、参考解法、个人身份和调试日志都应排除。

## 题内接口

| 接口 | 何时使用 |
| --- | --- |
| `practice.initialDraft` | 初始化时读取。第一次打开或点击题卡的「重置本题」后为 `null`，此时应显示初始画面。有草稿时先检查字段类型、范围和缺失值，再还原界面。 |
| `practice.saveDraft(value)` | 在学生改变选项、输入、拖放或撤回后调用，保存足以恢复当前操作的 JSON。存在尚未确认的输入时，一并保存。 |
| `practice.onGetState(handler)` | 初始化时注册一次。每次调用时，**同步返回此刻的公开 JSON**。回调只读，可以读取控件或交互模型，再将内部编号转换成名称。 |
| `practice.onCheck(handler)` | 初始化时注册一次。学生点击题卡的提交按钮时运行。可使用 `async`，并在函数内等待计算结束。 |
| `practice.correct(message, value)`、`practice.incorrect(message, value)` | 在每次检查的所有分支中恰好调用一个，返回公开反馈和本次实际提交值。省略 `value` 会使用最近的草稿。两者结构不同时请显式传值。 |

学生点击助教「发送」时，平台向当时的题卡取一次状态，随该条问题一同发送。修改控件、保存草稿、打开助教面板均不会发起模型调用。读取状态时请勿改界面、记分或保存草稿。旧题缺少回调、返回非法值或读取超时时，提问仍会发送，助教看到「本次提问的交互状态不可用」。上次提交的公开反馈和本次现场状态各自保留。

草稿、状态、提交值均须是 JSON 值，最多 16 KiB、嵌套 16 层。数值须有限且绝对值处于 JavaScript 安全整数上限以内。用数组表达顺序，用 `null` 表达空值；请勿返回 DOM 节点、函数、Promise、循环引用或 `undefined`。状态回调可返回 `null`，它表示题目明确给出了空状态。私有正确提交值必须是非 `null` 的 JSON，判题反馈最多 1,000 个字符。

服务端要求脚本返回正确，且实际提交值与私有正确提交值按类型和内容相等。数字 `2` 和字符串 `"2"` 不相等，对象的键顺序无关，数组顺序有效。当多种操作都正确时，应提交它们共同产生的结果。例如，学生可来回挪动物品多次，背包题只提交最终从栈底到栈顶的物品编号。

## 一个可以直接粘贴的例子

题干填「柜台上有 1 枚代币。每点击一次按钮增加 1 枚，请让柜台上恰好有 3 枚代币，再提交。超过 3 枚时可点击题卡的『重置本题』从头再试。」私有正确提交值填数字 `3`。HTML 填入以下内容，CSS 可留空。

```html
<p>柜台现有 <output id="count" aria-live="polite"></output> 枚代币</p>
<button type="button" id="add">增加一枚</button>
```

JavaScript 填入以下代码。

```js
const saved = practice.initialDraft?.count;
let count = Number.isSafeInteger(saved) && saved >= 1 ? saved : 1;
const output = document.querySelector('#count');
output.textContent = String(count);

function setCount(next) {
  count = next;
  output.textContent = String(count);
  practice.saveDraft({count});
}
document.querySelector('#add').addEventListener('click', () => setCount(count + 1));

practice.onGetState(() => ({柜台上的代币数: count}));
practice.onCheck(() => {
  if (count === 3) return practice.correct('正好是 3 枚。', count);
  practice.incorrect(count < 3 ? '再数数还差几枚。' : '已经超过 3 枚，可以重置再试。', count);
});
```

第一次运行预览，「查看助教收到的状态」应显示 `{"柜台上的代币数":1}`。点一次「增加一枚」再检查，提交值应为数字 `2`，判定错误。再加一枚后，助教状态应变成 3，提交值也应为数字 `3`，判定正确。在学生端加到 2 时切题再返回，应能从 2 继续。

## 保存校验与发布前试做

教师编辑器每次保存时会打开独立、空草稿的题面，实际加载脚本、读取初始助教状态，再执行一次提交检查。有私有目标时，还会核对这次的脚本判定与提交值是否一致。失败信息会指出加载、读取状态或检查作答中的哪一步出了问题。草稿可带警告保存，设为可用要通过校验。教师正在操作的预览保留原样。

保存校验只覆盖初始画面。发布前请试做这些场景。

- 先不操作就提交，再分别尝试一次有代表性的错答和正确作答。检查反馈是否告诉学生可以看哪里、改什么。
- 调整控件后、提交前，点击「查看助教收到的状态」。逐项对照屏幕，尤其注意边界值、空列表、尚未确认的输入及物品顺序。
- 在学生练习里切到别题再回来，核对画面、公开状态和能提交的值是否一同恢复。再点击「提交答案」旁的「重置本题」，检查画面和公开状态是否回到第一次打开时的值。平台会清除本题的操作草稿并重新运行题面脚本，教师只需处理好空草稿时的初始化。
- 改完源码后点「重新运行预览」。排查「脚本判定与私有答案不一致」时，先查看「本次提交值」，核对类型、数组顺序和真实结果。

## 题卡布局与资源

HTML 只填操作区的内容，事件处理放在 JavaScript 栏。HTML 和 JavaScript 各最多 32,000 个字符，CSS 最多 16,000 个字符。题面运行在隔离页面中，要用到的样式、逻辑和资源需随题自包含；图片可用内嵌 data URL，外部 CDN、字体服务和网络请求均不可用。题面源码会发给浏览器，适合演示公开规则与练习反馈。

常用主题变量有 `--paper`、`--surface`、`--ink`、`--muted`、`--forest`、`--line`、`--gold`。普通按钮、选择框、输入框自带题卡样式。可用 Canvas 绘图，另用文字显示当前结果。控件配上标签，为拖放提供可点击、可用键盘完成的操作，在窄题卡里试用一次。[路灯和背包模板源码](../shared/interactive-examples/)
