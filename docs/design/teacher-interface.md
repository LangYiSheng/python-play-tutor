# 后台界面规范

## 范围与入口

教师后台位于`admin/`，使用React、TypeScript与shadcn/ui，以`/teacher/`独立入口提供班级、学生、课程内容、教学流程和课程包维护。学生`/world`继续使用Vue + Phaser及[游戏规范](game-interface.md)，不按账号角色混用主题。课程变更遵守[数据与验证边界](../content-authoring.md#课程包验证边界)。

后台首页为班级管理。有可访问班级时，班级导航在全站页也保持可见，优先恢复本次会话上次选中的班级，否则使用第一个可访问班级。班级教学页显示当前班级与任课教师。创建班级可导入课程包、创建空课程或稍后配置；无课程时提供真实空状态。班级导入独立内容，不能借编辑甲班影响乙班。后台导航覆盖概览、学生、章节、知识点、资料、题库、活动、流程与课程包，不机械复刻旧Vue包装组件。

## 样式与组件边界

后台使用项目维护的shadcn/ui基础组件、Tailwind和Lucide，保留其许可与来源；组件源码可按实际需求调整。优先直接组合基础按钮、表单、表格和弹窗，只为重复业务抽取组件，不层层包装。主题与重置样式仅加载在后台HTML，不进入游戏入口。两个应用通过正常页面导航切换，不嵌套React/Vue根节点，不共享状态容器。

后台单选下拉统一使用 shadcn/ui Select，视图切换使用 Tabs 的 `line` 样式。管理列表使用 shadcn/ui Table，统一表头与单元格留白。搜索与本表相关的筛选放在表格上方，行尾显示单条操作。支持批量操作的列表使用复选框，选中后显示数量及可执行动作。只读差异表和统计表提供筛选与相应的查看入口。

## 账号、表格与状态

教师与管理员使用学号登录，学生搜索与详情显示学号，保留前导零。账号菜单包含修改密码和退出，改密使用当前密码、新密码及确认，不另设导航页；服务端撤销旧会话。正常退出或账号失效清空用户状态，旧请求结果不能写回另一个账号/班级。

学生列表默认25人/页，可选10/50/100，支持学号或姓名搜索、状态筛选和排序。表头只选本页，跨页保留选择，全部筛选最多500人。改变搜索或筛选清空选择并回第一页。CSV/XLSX先预览再确认，保留可修正错误。重置和移出可通过单行菜单或批量工具栏执行，确认框显示单条学号或批量人数。移出只取消成员关系，保留账号和学业证据。章节、资料与题目的单条及批量删除使用统一级联预览，批量原子执行；知识点独立删除仍使用原有权限与引用检查。

顶部“进入小镇”打开新标签页，使用当前教师在本班的专属体验学生。首次进入创建账号，再次进入恢复同一存档。体验学生遵循本班章节开放规则，可以完成任务并保存结果，菜单内可以确认重玩。名册、班级统计和正式学生记录中不显示该体验账号。

所有页面必须有加载、空、失败、保存中和成功状态。接口失败保留草稿；课程修订冲突要求刷新/重新预览，不能伪报成功或静默覆盖。关闭普通编辑弹窗即取消本次编辑，再打开时从已保存内容开始。切班或切页时只提醒仍在编辑的草稿，草稿和导入预览不得带入另一班。弹窗提供标题、标签、可见焦点、Tab边界和关闭后焦点恢复；请求期间防重复提交。

## 课程编辑

章节、资料、题目与活动的删除入口统一打开“删除影响范围”，分组列出一起删除、解除关联和保留的具体名称、原因与历史记录数量；长清单独立滚动。存在阻断时显示来源/位置并禁用继续。下一步为“最终确认删除”，输入目标名称（批量确认文字）并勾选已核对后才可执行，允许返回查看或取消。确认期间禁止重复提交与关闭；数据变化或过期须重新预览，清空旧确认。成功刷新当前班级列表。学生历史始终保留，具体级联规则见[内容规范](../content-authoring.md#级联删除与学生历史保留)。

章节支持发布、暂停、时间和前置；知识点、资料和题目通过结构化关联组织。练习的「类型」下方并排显示「固定题单」和「按知识点出题」，新建默认按知识点出题，编辑时显示原方式。活动列表标明出题方式。新增和编辑活动都从「活动信息」开始，最后一页是「内容关联」。阅读活动逐份配置资料的完成要求。固定题单和测验在「按知识点选题」中勾选本章题目，多知识点的题只加入一次。「题目顺序」支持按中文题名、章节内知识点顺序排列。活动列表的「选题」直接打开选题页。创建知识点练习时先选一个章节，再勾选本章知识点，左侧勾选并切换知识点，右侧仅编辑当前知识点的总数或题型要求。其他活动支持跨章节勾选知识点。资料可未归类上传、替换、预览，转换中和失败明确显示，不分必读/补充。题库先独立编写，来源仅AI生成/导入，审核状态为草稿/可用/停用，参考依据可选；有序活动选题是唯一关系来源，私有答案和用例不进入学生视图。

教学流程的公共与章节流程、地图交互与开放规则、任务目标与依赖、助教教学角色共用左侧工具区与右侧工作区。四个标签均使用图标配合文字，分别对应流程、地图、任务清单与助教。当前选择、新建和设置位于工作区顶部。右键节点打开浮动属性卡，键盘可用 Shift+F10，选中的卡片也有可点击的属性按钮。关闭属性后仍可操作画布。地图页保留固定对象选择、区域绘制及开放规则，助教页用角色卡管理配置与使用范围。

流程和任务画布使用 React Flow。左侧工具可拖入画布或点击添加，新增节点保留可连接端口，由教师手动连线。拖动期间保持节点可见，松手后记录位置。公共及章节流程共用条件、对白、选项、随机路由、活动等待与返回、界面操作、建筑解锁和结束节点。打开页面只设置目标工作区，需要提示时在前面连接对白；操作属性不显示旧提示或转换按钮。

从左侧「触发入口」选择角色或地图交互点，再连到起始节点。流程选择先选公共流程或章节，再选具体流程。对白选择角色时保存稳定 ID，显示随角色改名更新；自定义说话人用于旁白。任务目标与导航角色必须已放置。地图编辑器用游戏 Tiled 底图，交互标记和区域按逻辑格定位。

「助教教学角色」统一新增、编辑和删除角色，维护名字、立绘、地图像素外观和人设，显示放置状态；新增默认未放置。系统素材可直接选择，自定义图片直接上传，无需填写来源与授权，可预览精灵的方向和行走。上传中禁止保存；失败保留已有引用，取消编辑不会替换已保存资料。人设用于新建的学习/练习对话，已有会话保留原设定。课程开关、预算和默认答疑角色由“任务与设置 → 本班答疑设置”维护。

本班答疑设置沿用 `/teacher/settings` 路由。全站设置与本班答疑统一使用页面右上角的「取消编辑」「保存设置」，位置、图标、禁用/忙碌状态和未保存提示一致；只操作当前标签，切换标签保留各自草稿。正文统一使用「适用范围」「API 地址」「模型名称」「API Key」「请求超时（秒）」「每次回复上限（tokens）」等词。本班答疑对教师开放，其余全站连接由管理员维护。学生助教的「测试已保存连接」作为表单内独立次要操作，仅无草稿且有密钥时可点，产生一次短请求；保存不调用模型。密钥不回填明文，失败/冲突保留草稿。

语音接口切换时提供对应示例：DeepSeek 自动使用 Stella、WAV 和固定语速1，隐藏不适用的模型及语速输入，音色/格式只显示支持值；保留自定义地址与密钥，明确「填入示例」可替换非密钥字段，保存前不生效。地址允许基础地址、`/v1` 或完整语音路径，避免重复拼接。语音设置页的模型与音色提供可点选下拉：模型合并实时列表与内置列表，音色为内置常用中文列表并允许手填；保存后可用「测试已保存连接」发送一次短合成，存在未保存修改时按钮禁用。

「地图交互与开放规则」的角色工具显示已放置与未放置角色，选中后点击地图放置、拖动移动，或输入坐标；配置朝向、出现条件及撤回放置。角色资料与地图位置共享同一草稿，不再有独立提交的新增角色弹窗。删除与撤回产生的引用阻断显示来源并可定位；改名、换图和人设编辑不重置学习进度。

未保存状态显示在保存按钮旁边。「取消编辑」经确认恢复本班上次保存的课程，包括四个标签中的修改和布局。服务端仍校验图引用、条件、可达位置及历史影响。按真实学生状态运行的流程预览是只读检查，体验学生入口独立保存自己的游玩进度。

「校验」列出问题、修复建议和可用的「定位」入口。定位会切到对应标签，并选中具体流程、入口、节点或配置项。涉及重置的改动显示独立警告，列出本班受影响的流程、任务和人数，保存时需再次明确确认。已完成的互动、尚在继续的互动与任务进度按各自影响范围处理。仅修改仍在使用的地图入口规则时，可先在小镇完成或点击「结束本次互动」。关闭网页或暂时离开会保留互动。

课程包页选择data/course下的解压目录，共用差异、学习影响与阻断项预览。ZIP上传关闭。等待时显示动态处理状态和真实等待秒数；导出完成后显示服务器目录路径。教师查看预览后确认导入，过期或课程变化须重做。对白节点按轮次显示独立输入框，支持添加与删除对白，沿用空行分轮的存储格式，分支可以连接各自附近的独立结束节点。全包包含私有答案，交换目录保持服务端私有。

## 评测管理

侧栏“评测管理”进入 `/teacher/judge`。上方展示连接状态和本班等待/执行/待核查/服务异常数量；每10秒刷新，失败显示错误，旧数据显示时不得隐藏刷新失败。正常检测时间、耗时和心跳折叠到“运行详情”，异常连接或心跳仍直接显示。管理员在全站设置查看跨班提交、全站实时队列与最近50条服务事件，并立即检测、暂停或恢复全站派发；改变派发设置前填写原因并确认全站影响。暂停不终止已执行请求。

下方提交表按姓名、学号、题目或完整提交编号检索，可筛选状态、分页。详情展示代码、原始用例快照、实际与预期输出、错误输出、CPU耗时、内存及开始/结束时间。隐藏用例标注教师私有；排查建议是明确的可能方向，不声称自动判断根因。历史诊断缺失与未执行用例分别显示，不自动补跑。普通浏览器公开样例试运行不上传；练习正式提交只保存浏览器评测回执，不进入此页的列表、统计或详情。此页仅管理服务器评测。切班、切账号、离页时关闭私有详情并取消请求；后台页面不提供改分、容器命令或盲目重判。

评测页顶部提供统一日期筛选，默认近七天，可选近一天/七天/三十天、全部时间或自定义起止日期。快捷项按后台时区自然日计算并包含今天，起止日期均包含整日；输入日期后点击“应用日期”，错误时保留已应用范围。切换范围清空已开详情并回到第一页，统计与提交请求共同应用；连接/心跳及明确标注的全站实时队列不随日期过滤，避免遗漏旧待处理任务。服务事件只从最近50条留存事件中按发生时间筛选，空范围明确展示空态。异常数字表示范围内提交的当前结果，不代表当前服务必定异常。

评测日期工具条将“统计日期”、快捷项、起止输入与应用按钮紧凑排列，窄屏自然换行；起止输入保留无障碍名称，不再重复展示当前范围和自然日解释。统计下方仅标注“本班 · 所选日期”。

## 验收要求

以1920×1080桌面Chromium为基准，验证登录/改密/退出、分页与批量范围、上传/替换/真实预览、活动复用、流程保存、按真实学生只读预览、课程包往返和跨班独立。验证键盘焦点、错误保留、并发冲突、同域深链刷新及后台/游戏样式隔离。按[验证方法](../development.md#基础检查)选择受影响的场景，实际结果与未覆盖范围在交付回复中说明，不以页面存在代替验证通过。

课程包列表采用可搜索表格，显示完整课程名称、创建日期、章节数、题目数和实际文件夹名，行尾提供预览导入；全站共享导出的包另提供“删除”，其他服务器复制来的导出包同样可操作；默认包显示“受保护”。页面说明所有教师均可导入，只有管理员可删除共享导出包。删除前用统一确认弹窗展示课程名和文件夹，说明从全站共享目录删除、不影响已导入的班级课程与学生记录；请求中禁用操作，失败保留弹窗和原因。长名称和目录换行显示，取消列表外的底部分隔线。目录创建日期优先采用清单 exported_at，缺省使用 created_at，按后台时区展示。

角色配置使用基础信息、对话立绘、像素角色三个标签；素材使用带缩略图的限高滚动下拉，显示系统/此角色自定义标记与帧尺寸。本班答疑设置统一保存/取消开关、默认答疑角色与预算，使用课程修订控制并保护未保存草稿。活动答疑角色默认选择“使用课程默认角色”，也可指定本班角色；测验仍禁用助教。地图角色摆放时左侧列出角色与放置状态，右侧维护位置、朝向、条件。

全站设置分为智能体设置、资料合成管理、评测管理。学生助教、讲稿生成、语音合成仅管理员可配置，各自独立保存和校验修订；保存不会调用模型或配音。

侧栏顶部品牌和底部账号固定，中间菜单可滚动。班级概况可分别修改班级名称和本班课程名称。选班下拉菜单按选项内容展开，长名称换行显示。班级管理提供创建入口；班级选择器位于顶栏“进入小镇”左侧，管理员按“任课教师 | 班级名称”展示，教师只看到自己的班级名称。无需选班的侧栏入口为班级管理、全局概览、教师管理、学生管理、全站设置。后四项仅对管理员开放。学生管理支持组合搜索姓名、学号和所属班级，归档班级仍可筛选。选班后的四组为班级教学（班级概况、学生账号、教学管理）、课程内容（课程结构、资料库、题库）、课程编排（学习活动、教学流程、课程包）、任务与设置（本班答疑设置、资料合成管理、评测管理）。班级页仅展示当前班级数据；管理员在全站设置中管理全站队列。

## 编程题编辑

题库和课程结构中的知识点列表默认每页 10 条，服务端处理搜索、筛选与分页。题库表格读取摘要，打开编辑器才读取该题完整内容。新增和编辑均在「题目信息」中维护题名、题型、状态和题干，在「内容关联」中按章节勾选知识点并填写参考资料。客观题在「答案」中配置作答规则。编程题分别编辑初始代码与分步提示、测试用例。公开样例与私有用例分组，可逐条添加、复制、修改或移除。活动选题继续混排，助教继承课程默认角色或活动指定角色，不增加专用编程活动。

全站字体修订：正文与控件使用 -apple-system、BlinkMacSystemFont、Segoe UI、Noto Sans SC、sans-serif；标题使用加粗宋体回退链，代码仍使用等宽字体。后台沿用自身主题，内容面板和工具栏留白收紧。

资料库只对 PDF、演示文稿显示「课程生成」审校与试听入口，服务端同步校验类型。弹窗内只留「审校／校准」两个页签：审校页逐页对照原页、讲解，并把整理稿与原始文本左右并排便于比对；校准报告单独成页，不再挤在审校上方。顶部把「一键梳理文本」「生成全文配音」「接受全部草稿」并排。标题、主题与标签只读展示，不开放逐页手改。试听使用居中大弹窗（最大1400px、85vh），保留背景工作台；语速使用共享 Select，关闭后归还焦点。保留原文/页图、草稿、接受/拒绝、显式生成/校准/合成音频。“全篇校准”、整份生成与批量音频点击后只提交任务，界面轮询任务进度（已检查窗口/总窗口）并显示“任务在后台继续，可以切去别的资料”；重新打开资料时若任务仍在跑，直接显示进度而不重复提交。报告区标出是否复用上次报告、模型缓存命中率、按缩减预算完成的窗口与无法渲染页图的页；未完成的报告只读且禁止应用。报告按原文修正、标签合并、问题三个分区折叠：原文修正与问题默认展开，标签合并默认收起并按标准名分组列出别名；问题按页归并，只记录不改整理稿。旧校准报告遇到教师编辑或接受后的页面只列待核查，不能自动覆盖；任务失败即解除占用。切换班级/资料和退出时丢弃旧媒体请求并释放资源。学生提问配置统一位于智能体设置，不提供第二份学生模型密钥。


## 资料合成管理

`/teacher/synthesis` 按每次任务展示，使用带图标的“正在执行”“历史记录”标签；当前班级隔离，按资料名称和执行状态筛选并分页。每次生成、校准、配音独立一行，显示任务编号、资料、类型、页范围、发起人、进度、开始/结束时间及失败页/原因。每5秒刷新，失败可见且保留上次结果；切班/离页取消读取，零模型调用。查看资料与试听为次要动作。重试产生新记录，原失败永久保留；这里只承诺升级后历史，升级前仅回填现存最后一次任务。已删除资料保留历史展示，关闭其查看/重试入口。

明确失败且参数完整的任务允许教师确认后重试；提示实际可能产生费用，按钮防重复。批次只重试记录的失败页。中断待核查、旧参数缺失或校准修复类任务须先进入审校，不盲目重放。服务端核对任务标识、内容指纹和所有权；资料或讲稿变化、并发新任务及重复请求均拒绝旧重试。不会自动接受草稿或修改学生数据。

题库题型包含单选、多选、判断、填空、编程及交互练习题。多选编辑器使用复选框标记正确选项；改名同步已选答案，清空或删除选项移除对应答案。至少两个正确选项才可设为可用，未完成内容可保存待审核。

交互练习题编辑器提供 HTML、CSS、JavaScript 和私有 JSON 目标。运行预览后，教师可以操作学生题面，点击「检查预览作答」核对判定，点击「查看助教收到的状态」读取当前公开状态。保存时编辑器从空草稿试跑，指出加载、读取或判定错误。草稿允许保存，设为可用须通过。练习可配置这种题型，测验的选题范围排除它。[编写指南](../interactive-practice-authoring.md)
