# 后台界面规范

## 范围与入口

教师后台位于 `admin/`，使用 React、TypeScript 与 shadcn/ui。教师从 `/teacher/` 管理课程、班级、学生和课程包，在章节详情维护资料，在活动管理中布置练习与测验。学生小镇沿用[游戏规范](game-interface.md)。课程变更遵守[数据与验证边界](../content-authoring.md#课程包验证边界)。

登录首页以卡片显示本人负责的课程。首张卡片创建课程，先填写名称，再选择创建空课程或从可用课程包导入，每张课程卡提供「进入课程」，更多菜单可修改课程名称、导出课程包或转交课程。转交时按姓名或工号搜索，在候选列表中选定教师后确认。右上账号菜单提供改密和退出。管理员通过「进入后台」访问全局概览、教师管理、学生管理、资料合成管理、评测管理与全站设置。

## 样式与组件边界

后台使用项目维护的shadcn/ui基础组件、Tailwind和Lucide，保留其许可与来源；组件源码可按实际需求调整。优先直接组合基础按钮、表单、表格和弹窗，只为重复业务抽取组件，不层层包装。主题与重置样式仅加载在后台HTML，不进入游戏入口。两个应用通过正常页面导航切换，不嵌套React/Vue根节点，不共享状态容器。

同一工具栏内的同级操作使用相同的按钮样式、字号、图标大小和间距，宽度随文字与数量自然变化。跳转页面使用保留原生链接行为的 `ButtonLink`，执行操作或展开面板使用 `Button`。图谱的「待审批」与「任务队列」都以「数量 + 项」显示已读取的计数。纯图标按钮提供具体的无障碍名称与悬浮提示，例如「编辑第一章」。

常用动作复用 Lucide 的固定图标：新增用加号、上传用向上箭头、编辑用铅笔、复制用双页、预览用眼睛、讲稿审校用带笔的笔记本、试听用耳机。移除活动中的资料关联用叉号，删除资料本身用垃圾桶。全站管理与本班教学的侧栏图标按入口用途区分。

后台单选下拉统一使用 shadcn/ui Select，选项面板按内容展开，在视口边界内换行显示长名称。视图切换使用 Tabs 的 `line` 样式。管理列表使用 shadcn/ui Table，统一表头与单元格留白。搜索与本表相关的筛选放在表格上方，行尾显示单条操作。支持批量操作的列表使用复选框，选中后显示数量及可执行动作。只读差异表和统计表提供筛选与相应的查看入口。

搜索与筛选靠左排列，新增操作与列设置靠右排列，工具栏与表头之间保留间距。空列表直接显示空状态。管理表格在工具栏提供列设置，可隐藏次要字段并调整左右冻结列数。横向滚动条与未冻结区域对齐，窄屏优先保留可滚动空间。后台表格默认每页 10 条，分页位于表框下方，结果只有一页时收起。多个次要筛选可在「更多筛选」中组合，日期范围使用双月日历和快捷日期。

## 账号、表格与状态

列表为空时按原因给出下一步。尚无可维护的数据时，按当前权限提供创建或导入入口；筛选无匹配时提供重置筛选；只读记录为空时说明记录来源。

操作完成、连接测试等简短反馈统一使用 shadcn/ui Toast。字段错误、修订冲突、加载进度与需继续使用的结果保留在对应区域。

教师与管理员使用工号登录，工号与学号均保留前导零。每次输入凭据登录后进入「课程选择」。当前会话刷新时可恢复已授权页面。账号菜单包含修改密码和退出；输入新密码后实时提示长度与确认结果。首次登录进入设置密码弹窗，保存后进入工作台。正常退出或账号失效清空用户状态。

学生列表可切换为每页 25、50 或 100 人，支持学号或姓名搜索、状态筛选和排序。表头只选本页，跨页保留选择，全部筛选最多500人。改变搜索或筛选清空选择并回第一页。CSV/XLSX先预览再确认，保留可修正错误。行尾并排提供重置密码和移出班级按钮；批量工具栏支持两项操作，确认框显示单条学号或批量人数。移出只取消成员关系，保留账号和学业证据。全站教师与学生管理的行尾直接显示「修改姓名」和「重置密码」，更多菜单提供停用、启用和删除。永久删除先说明级联范围，再输入工号或学号确认。章节、资料与题目的单条及批量删除使用统一级联预览，批量原子执行；知识点独立删除仍使用原有权限与引用检查。

顶部“进入小镇”打开新标签页，使用当前教师在本班的专属体验学生。首次进入创建账号，再次进入恢复同一存档。体验学生遵循本班章节开放规则，可以完成任务并保存结果，菜单内可以确认重玩。名册、班级统计和正式学生记录中不显示该体验账号。

所有页面必须有加载、空、失败、保存中和成功状态。接口失败保留草稿；课程修订冲突要求刷新/重新预览，不能伪报成功或静默覆盖。关闭普通编辑弹窗即取消本次编辑，再打开时从已保存内容开始。切班或切页时只提醒仍在编辑的草稿，草稿和导入预览不得带入另一班。弹窗提供标题、标签、可见焦点、Tab边界和关闭后焦点恢复；请求期间防重复提交。

## 课程内容工作区

课程导航的“知识图谱”打开共享课程内容。课程全貌显示全部章节及资料，跨章资料保留每条章节关联。图谱占满顶栏下方的工作区，标题、搜索与任务队列悬浮在画布上。选中章节时右侧列出本章资料及知识点。选中课件可核对有明确页码依据的知识点，并查看已经生成的讲稿与有效配音。资料缺少可核对的出处时只显示已知归属。

点选知识点后在其下按页展开关联题目，也可打开按该知识点筛选的题库。搜索覆盖本班尚未展开的章节、资料、知识点和题目，选择结果即可定位。图谱沿用列表编辑器，保存后更新当前节点。教师可以平移、缩放或返回课程全貌。

任务队列展示本班正在执行的课件任务及近期需要关注的记录。当前阶段有明确总量时显示百分比和计量单位，失败和中断显示红色状态。教师可以取消运行中的批量任务，执行器会在步骤边界停止。取消失败任务可将其移出队列，资料合成管理保留失败历史与原因。符合重试条件的任务经确认后产生新的执行记录。

内容列表按章节、资料、知识点和题目切换，资料、知识点和题目由服务端分页。图谱的知识点详情可以打开带知识点筛选的题目列表。原课程结构、资料库和题库书签指向对应列表。

知识图谱右上角的「待审批」与「任务队列」各打开一张浮动卡片，一次展开一张。待审批的计数与卡片条目一致。每份有待审讲稿的课件占一项，当前教师可审核的题目合计占一项。

审批卡片按来源课件显示资料名称、PPT 或 PDF 格式及待审讲稿页数。跨章使用的同一份课件只出现一次，同章的多份课件各占一行。点击课件打开原有的「课程生成」界面，定位到首个待审页。教师可对照页面修改、接受或驳回讲稿。使用「接受全部草稿」时会确认本次课件的待审页数。

关闭课件审校后，卡片刷新待审数量，图谱保留教师的浏览位置。旧审批书签会打开图谱里的卡片，有可访问的课件标识时直接打开对应课件。「待审题目」打开内容列表的「待我审核」筛选，使用题库原有编辑器处理。逐页标签保留在课件审校中，教师确认的课程知识点独立维护。

## 章节编辑

教师在章节详情上传或关联资料。新资料默认选读，勾选必读后默认要求读完整份。高级设置支持指定页范围、任意不同页数、有效前台时间及组合条件，视频使用有效观看时长或片段。在「课程内容 → 活动管理」左侧选择章节，右侧列出活动名称、题量或知识点目标、必做状态与发布状态。教师可直接编辑已有活动或新增客观题练习、编程题练习和测验，设置选题、顺序和发布状态。每组练习可设为选做，测验均为必做。章节在各班独立开放、定时或暂停。

班级任务点明细按章列出各项资料、练习和测验及每名学生的实际进度。成绩页显示已交测验的判定结果。追加必读资料时，学生须先补读才可继续本章未完成的练习和测验。

## 评测管理

侧栏“评测管理”进入 `/teacher/judge`。上方展示连接状态和本班等待/执行/待核查/服务异常数量；每10秒刷新，失败显示错误，旧数据显示时不得隐藏刷新失败。正常检测时间、耗时和心跳折叠到“运行详情”，异常连接或心跳仍直接显示。管理员在后台的「评测管理」查看跨班提交、全站实时队列与最近50条服务事件，并立即检测、暂停或恢复全站派发；改变派发设置前填写原因并确认全站影响。暂停不终止已执行请求。

下方提交表按姓名、学号、题目或完整提交编号检索，可筛选状态，默认每页 10 条提交。详情展示代码、原始用例快照、实际与预期输出、错误输出、CPU耗时、内存及开始/结束时间。隐藏用例标注教师私有；排查建议是明确的可能方向，不声称自动判断根因。历史诊断缺失与未执行用例分别显示，不自动补跑。普通浏览器公开样例试运行不上传；练习正式提交只保存浏览器评测回执，不进入此页的列表、统计或详情。此页仅管理服务器评测。切班、切账号、离页时关闭私有详情并取消请求；后台页面不提供改分、容器命令或盲目重判。

评测页顶部提供统一日期筛选，默认近七天，可选近一天/七天/三十天、全部时间或自定义起止日期。快捷项按后台时区自然日计算并包含今天，起止日期均包含整日；输入日期后点击“应用日期”，错误时保留已应用范围。切换范围清空已开详情并回到第一页，统计与提交请求共同应用；连接/心跳及明确标注的全站实时队列不随日期过滤，避免遗漏旧待处理任务。服务事件只从最近50条留存事件中按发生时间筛选，空范围明确展示空态。异常数字表示范围内提交的当前结果，不代表当前服务必定异常。

评测日期工具条将“统计日期”、快捷项、起止输入与应用按钮紧凑排列，窄屏自然换行；起止输入保留无障碍名称，不再重复展示当前范围和自然日解释。统计下方仅标注“本班 · 所选日期”。

## 验收要求

以 1920×1080 桌面 Chromium 验证登录、改密、退出、分页与批量范围、课件上传及预览。在章节中发布任务点后，用同班学生核对资料可见性、两类练习的解锁、测验和任务点明细。另核对课程包往返与跨班隔离、键盘焦点、错误保留、并发冲突和深链刷新。验证范围见[开发手册](../development.md#基础检查)。

首页的「课程包管理」以卡片显示本人导出的课程包，可搜索、创建独立课程、删除导出包或在导入差异弹窗核对后更新已有课程。来源筛选可访问历史共享包和预置包。

管理员在全站设置的教学角色页选择图书管理员、教授、练习场教练或镇长，修改名称、人设、立绘与像素形象。使用内置素材时可预览，上传自定义像素图时须填写帧尺寸。保存后同一配置用于全平台的地图、对白与答疑。四个角色分别驻守图书馆、教学工坊、练习会馆和镇长办公室。

全站学生助教设置维护统一开关、模型和预算，默认开启答疑。讲稿生成和语音合成使用独立的管理员表单。保存设置和编辑固定角色均不调用模型。

教师登录进入课程选择，可创建、进入或修改自己的课程。管理员可将课程连同所属班级转交给其他教师。进入课程后，知识图谱、内容列表和章节任务点配置均可直接使用。班级管理按行展示班级加入码与学生数，可复制在教班级的加入码，从「学生管理」进入本班名册。班级页面优先采用链接指定的有效班级，再恢复当前教师在该课程最近使用的班级，首次进入选取首个在教班级。单班直接展示班名，多班可切换，尚未开班时提供创建入口。

课程主导航依次显示「班级管理」「学情统计」「定时开放」。「学情统计」在侧栏内展开，学情洞察展示整课汇总，任务点明细和学生成绩按班呈现。课程内容按章布置资料、练习和测验。

## 编程题编辑

题库和课程结构中的知识点列表默认每页 10 条，服务端处理搜索、筛选与分页。题库表格读取摘要，打开编辑器才读取该题完整内容。新增和编辑均在「题目信息」中维护题名、题型、状态和题干，在「内容关联」中按章节勾选知识点并填写参考资料。客观题在「答案」中配置作答规则。编程题分别编辑初始代码与分步提示、测试用例。公开样例与私有用例分组，可逐条添加、复制、修改或移除。章节内客观题练习只选客观题和交互题，编程题练习只选 Python 题。测验可混排客观题和编程题。

全站字体修订：正文与控件使用 -apple-system、BlinkMacSystemFont、Segoe UI、Noto Sans SC、sans-serif；标题使用加粗宋体回退链，代码仍使用等宽字体。后台沿用自身主题，内容面板和工具栏留白收紧。

资料库只对 PDF、演示文稿显示「课程生成」审校与试听入口，服务端同步校验类型。弹窗内只留「审校／校准」两个页签：审校页逐页对照原页、讲解，并把整理稿与原始文本左右并排便于比对；校准报告单独成页，不再挤在审校上方。顶部把「一键梳理文本」「生成全文配音」「接受全部草稿」并排。标题、主题与标签只读展示，不开放逐页手改。试听使用居中大弹窗（最大1400px、85vh），保留背景工作台；语速使用共享 Select，关闭后归还焦点。保留原文/页图、草稿、接受/拒绝、显式生成/校准/合成音频。“全篇校准”、整份生成与批量音频点击后只提交任务，界面轮询任务进度（已检查窗口/总窗口）并显示“任务在后台继续，可以切去别的资料”；重新打开资料时若任务仍在跑，直接显示进度而不重复提交。报告区标出是否复用上次报告、模型缓存命中率、按缩减预算完成的窗口与无法渲染页图的页；未完成的报告只读且禁止应用。报告按原文修正、标签合并、问题三个分区折叠：原文修正与问题默认展开，标签合并默认收起并按标准名分组列出别名；问题按页归并，只记录不改整理稿。旧校准报告遇到教师编辑或接受后的页面只列待核查，不能自动覆盖；任务失败即解除占用。切换班级/资料和退出时丢弃旧媒体请求并释放资源。学生提问配置统一位于智能体设置，不提供第二份学生模型密钥。


## 资料合成管理

`/teacher/synthesis` 按每次执行展示，分为“正在执行”和“历史记录”。教师可按资料名称、执行状态筛选和分页查看本班任务。打开任务详情可查看类型、资料、处理范围、当前阶段、进度与失败位置。按批处理时标明计数单位，有确切记录时展示对应页码。一键生成分阶段展示，只有语音合成任务提供试听入口。每 5 秒刷新，切班或离页时取消读取。重试产生新记录，历史保留每次执行的结果。已删除资料的记录可供查询。

明确失败、已取消或服务重启前尚未执行的任务，具有原参数与内容指纹时允许教师确认后重试；提示实际可能产生费用，按钮防重复。批次只重试记录的失败页。执行中断且结果待核查、旧参数缺失或校准修复类任务须先进入审校，不盲目重放。服务端核对任务标识、内容指纹和所有权；资料或讲稿变化、并发新任务及重复请求均拒绝旧重试。不会自动接受草稿或修改学生数据。

题库题型包含单选、多选、判断、填空、编程及交互练习题。多选编辑器使用复选框标记正确选项；改名同步已选答案，清空或删除选项移除对应答案。至少两个正确选项才可设为可用，未完成内容可保存待审核。

交互练习题编辑器提供 HTML、CSS、JavaScript 和私有 JSON 目标。运行预览后，教师可以操作学生题面，点击「检查预览作答」核对判定，点击「查看助教收到的状态」读取当前公开状态。保存时编辑器从空草稿试跑，指出加载、读取或判定错误。草稿允许保存，设为可用须通过。练习可配置这种题型，测验的选题范围排除它。[编写指南](../interactive-practice-authoring.md)
